# 전산팀 업무관리 · IT WORKSPACE

## 참고 이미지 반영 및 공통 매핑

대시보드에 상태별 KPI 6개, 파트별 누적 막대, 상태 비율 도넛, 최근 4주 추이, 주요 진행업무·진행률, 공지사항을 적용했습니다. 통계 분석과 장비지원 분석은 저장된 실제 업무를 집계합니다. 진행률·시작일·요청부서·장비 종류는 업무 상세에서 입력할 수 있습니다. 공지 등록·수정·상단 고정·보관을 지원합니다.

**관리자 설정 → 엑셀 공통 매핑 사전 설정**에서 헤더 행, 필드별 컬럼, 담당자 확인 방식, 상태 매핑을 저장하세요. 개발자별 시트 양식이 같다는 전제로 한 번 저장한 설정을 모든 선택 시트에 공통 적용하며 다음 업로드에서도 불러옵니다. 업로드 화면에서 조정한 매핑도 관리자 설정에 저장할 수 있습니다. 컬럼은 실제 엑셀 순서대로 지정합니다(1열=A, 2열=B).

파트는 엑셀 파트 컬럼 대신 **관리자 설정의 직원별 소속 파트**에서 자동 결정합니다. 담당자 컬럼이 없고 시트명이 직원명과 같으면 ‘시트명 = 직원명’을 선택하세요. 미등록 또는 여러 파트에 중복 등록된 직원명은 검증 오류로 표시되며 임의 배정하지 않습니다. 기존 업무의 파트 스냅샷은 변경되지 않습니다.

DB 없이 JSON 파일에 저장하는 로컬 웹 프로그램입니다. 기존 예배 프로그램의 모던 다크 테마(#0D1420 / #192536 / #18A6A0)를 적용했습니다. 외부 서비스, CDN, AI 전송은 사용하지 않습니다.

## 실행

1. **start.bat**을 더블클릭합니다. Node.js 22 이상이 필요합니다. 현재 PC에서는 Codex에 포함된 Node.js도 자동으로 찾습니다.
2. 브라우저에서 http://127.0.0.1:4317 에 접속합니다. 처음 시작할 때 브라우저가 먼저 열리면 새로고침하세요.
3. 종료는 실행 창에서 Ctrl+C입니다. 서버 종료 후에도 저장 데이터는 유지됩니다.

패키지 설치 없이 실행됩니다. 명령줄에서는 `node server.mjs`, 검증은 `node --test tests/*.test.mjs`를 사용합니다. 포트는 환경변수 `PORT`, 저장 폴더는 `IT_DATA_DIR`로 변경할 수 있습니다. 주소와 서버 포트는 함께 바꾸세요.

## 구현 기능

- 통합·주간·월간 대시보드, 파트별 누적막대, 신규/완료/잔여 추세, 업무구분 분포와 지연 알림
- 업무 직접 등록·수정, 공동담당, 목표일, 보류 사유, 완료 후 재오픈 사유와 상태·활동 이력
- 등록일/활동일/완료 전이일과 상태 기준일을 분리한 집계 및 원본 업무 추적
- XLSX·CSV 업로드 → 시트 선택 / 공통 헤더·컬럼 매핑 → 검증·중복 후보 검토 → 행별 신규/갱신/활동/제외 → 확정
- 파일 SHA-256 재반영 차단, 원본 셀·시트·행 보존, 오류 CSV와 반영 취소
- 보고서 수동 작성·확정, 데이터 스냅샷 보존, JSON 다운로드, 인쇄/PDF
- 파트별 직원·업무구분 설정, 전체 JSON 백업 다운로드, 저장 시 자동 백업

## 파일 구조

```
server.mjs                로컬 HTTP 서버 / 저장·업로드 API
lib.mjs                   입력 검증 / 상태 기준일 / 집계
public/                   브라우저 화면 / 스타일
scripts/read-xlsx.ps1     Windows 기본 .NET ZIP·XML 엑셀 파서
tests/                    집계·이력·업로드 통합 검증
data/work-data.json       저장 데이터 (최초 실행 시 생성)
data/backups/             매번 저장 직전 전체 데이터 백업
```

데이터는 브라우저 저장소가 아니라 서버가 실행된 PC의 파일입니다. 브라우저를 닫거나 서버를 재시작해도 유지됩니다. JSON은 임시 파일을 완성한 후 교체하며 요청은 순서대로 저장합니다. 손상된 기존 데이터 파일은 임의로 초기화하지 않고 시작을 중단합니다. 동일 저장 폴더에는 서버 하나만 실행하세요.

## 엑셀 사용

XLSX는 Microsoft Excel 설치 없이 Windows PowerShell/.NET으로 읽습니다. CSV는 UTF-8만 지원합니다. 최대 파일 크기 10MB, 압축 해제 80MB, 전체 20,000행, 150열을 지원합니다. 암호화 파일·매크로 XLSM은 받지 않습니다. 매크로·수식을 실행하지 않으며 수식은 저장된 계산 결과만 읽습니다. 별도 악성파일 검사 엔진은 포함되지 않습니다.

개인별 시트·집계 시트 중 필요한 시트만 직접 선택합니다. 담당자는 등록된 직원명과 일치해야 하며 복수 담당자는 쉼표 또는 `/`로 구분합니다. 담당자명 별칭을 자동 추정하지 않습니다. 파트는 항상 관리자 직원 마스터에서 자동 반영하며 엑셀 파트 값은 사용하지 않습니다. `개발중→진행`, `처리완료→완료`가 기본 매핑이며 추가 상태는 `처리중=진행, 대기=접수` 형식으로 지정합니다. 분류 숫자는 초기 업무구분 순서(1~14)에 대응합니다.

제목·담당자는 필수입니다. 빈 등록일은 지정한 활동일, 빈 상태는 접수, 빈 분류는 기타를 사용하며 검증 화면에서 확인할 수 있습니다. Excel 날짜 일련번호와 YYYY-MM-DD / YYYY.MM.DD / YYYY/MM/DD를 지원합니다. 병합셀은 임의로 전파하지 않습니다. 모든 선택 시트에 적용할 공통 헤더 행을 선택하고 필요한 경우 원본을 정리하세요. 외부 업무ID와 동일 제목은 후보만 제시하며 자동 병합하지 않습니다.

반영 후 수정된 업무가 있으면 취소를 거부합니다. 후속 업로드를 먼저 되돌리거나 해당 업무를 직접 검토하세요. 배치·감사 이력은 취소 후에도 남습니다.

## 집계 규칙

고유업무는 ID별 1건, 파트 참여는 업무별 중복 없는 파트 수입니다. 취소는 기본 집계에서 제외합니다. 완료율은 기준일 상태가 완료인 건수 / 선택 기간 고유업무 수이며 0건은 `—`입니다. `완료 전이일` 기준은 해당 기간 완료 이력이 있는 고유업무를 선택하며, 이후 재오픈한 경우 기준일의 상태가 진행일 수 있습니다. 화면 상단에 기간과 기준을 항상 표시합니다.

추세의 신규는 각 구간 등록업무, 완료는 각 구간 완료 전이 고유업무, 미완료는 구간 말(기준일을 초과하지 않음)의 누적 미완료입니다. 월간 확정 보고는 필터와 문구 및 원본 업무 복사본을 보존합니다. CSV 내보내기는 Excel에서 열 수 있으며 수식 시작문자를 이스케이프합니다.

## 백업·복원·운영 범위

관리자 설정 → 전체 데이터 백업으로 내려받거나 서버 종료 후 `data` 폴더를 복사하세요. 복원은 서버를 종료하고 현재 파일을 별도 보관한 뒤 원하는 백업을 `data/work-data.json`으로 복사하고 재시작합니다. 자동 백업 보존기간은 아직 자동 정리하지 않으므로 필요에 맞게 관리하세요.

현재는 **127.0.0.1 전용 단일 관리자 프로그램**이며 로그인·네트워크 공동사용·파일 암호화는 포함하지 않습니다. 원본과 백업은 평문이므로 OS 폴더 권한으로 관리하세요. 사내 다중 사용자 운영은 인증과 파일 잠금·백업 정책을 추가한 후 별도로 구성해야 합니다. AI와 PPT 자동생성은 미연결로 표시되며, 실제 운영 Excel 및 PPT 양식이 제공되면 매핑을 추가할 수 있습니다.

누적 업무일지 업로드는 기본적으로 선택 주차와 예정 업무만 반영합니다. 공통 매핑에서 주간구분 컬럼을 한 번 연결·저장한 뒤 반영 주차(예: 10월4주)를 확인하세요. 주간구분이 선택 주차/예정인 행 또는 상태가 예정인 행을 포함합니다. 파일의 가장 최근 주차를 제안하며 업로드 시 확인·변경할 수 있습니다. 전체 과거 자료를 최초 적재할 때만 해당 필터를 해제하세요.
